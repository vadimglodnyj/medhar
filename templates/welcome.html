Що покласти в папку data

Шлях на вашому комп’ютері (для орієнтації): {{ data_dir }}

Файл Опис
treatments_YYYY.xlsx Річна база: у назві рік з 4 цифр, наприклад treatments_2026.xlsx. Можна кілька років одночасно.
base.xlsx Кадрова база для рапортів і службової характеристики (ПІБ, звання, посада).
outpatient_journal.db Локальна SQLite-база амбулаторного журналу (створюється автоматично на сторінці Амбулаторний журнал).
payments/may_2026.xlsx … Щомісячні відомості проведених оплат (англійська назва місяця + рік). Потрібні для сторінки Оплати / Відомість.

Потрібні колонки: Прізвище, Ім'я, По батькові або колонка ПІБ. Файли *.xlsx у data не потрапляють у git — їх додаєте лише у себе на диску. Оновлювати файли зручніше на сторінці Бази даних.

Встановлення (мінімум для роботи)

  1. Встановіть Python 3.8+ з python.org і у вікні інсталятора увімкніть Add python.exe to PATH.
  2. Windows: подвійний клік на start_medchar.bat — створиться venv і встановляться залежності з requirements.txt (лише те, що потрібно для цієї програми).
  3. Вручну: python -m venv venv → активуйте venv → pip install -r requirements.txt → python app.py.
  4. Відкрийте в браузері цю сторінку або одразу форму медичної характеристики.
